# S5.2c First-contact WhatsApp invitations

Status: draft

## Goal

Enable a clinic to send an automatic booking invitation to an eligible patient when no
WhatsApp conversation exists, using a supported messaging provider and synthetic tests.

## Why this is deferred

The pinned OpenWA v4 bridge fails on a saved test contact when no chat exists. An isolated
v5 experiment did not reach pairing, so its first-contact behavior remains unverified.
Patient-initiated booking and invitations to an existing chat are covered by S5.2a/b.

## Decisions required before approval

- Choose a provider and confirm its eligibility, pricing, consent and template rules.
- Define a safe live test with dedicated test phones and no real patient data.
- Keep uncertain delivery outcomes visible and prevent automatic duplicate sends.
- Specify the provider interface, authorization, audit, tests and review evidence.

No implementation is approved by this draft.
